# ATM Simulator in Python

## Project Overview

This project is a command-line based ATM (Automated Teller Machine) simulator built with Python. The application simulates the core functionalities of a real-world bank, allowing users to create accounts, log in, and manage their funds through a simple and interactive menu. This project serves as a practical demonstration of Object-Oriented Programming (OOP) principles and the implementation of fundamental data structures from scratch.

## Features

* **Account Management**: Users can create a new bank account or log in to an existing one.
* **Secure Access**: A simple login system ensures users can only access their own account details.
* **Core Banking Functions**:
    * **Check Balance**: View the current account balance.
    * **Deposit**: Add funds to the account.
    * **Withdraw**: Withdraw funds, with checks for sufficient balance.
* **Transaction History**: View a complete history of all transactions for the logged-in account.
* **Interactive Menu**: A user-friendly, menu-driven interface guides the user through all available options.
